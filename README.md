# Cadastro de Ninjas

API REST desenvolvida durante meus estudos de Java e Spring Boot.

## Tecnologias

- Java 25
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- H2 Database
- Flyway
- Lombok
- Swagger/OpenAPI

## Funcionalidades

- Cadastro de ninjas
- Listagem de ninjas
- Consulta por ID
- Atualização
- Exclusão
- Cadastro de missões
- Associação entre ninjas e missões
- Documentação da API

## Arquitetura

Controller -> Service -> Repository -> Database

DTO ↔ Mapper ↔ Model
